# Conference REST API

Simple RESTful service for managing conferences and sessions.

Built with **Python** and **Flask**.

## Features

- Manage conferences
- Manage sessions
- JSON REST API

## Tech Stack

- Python
- Flask
- Pydantic
- SQLAlchemy

## Run locally

```bash
git clone <repo>
cd <repo>
pip install -r requirements.txt
python app.py
```

## API

Example endpoints:

```
GET /api/v1/conferences
POST /api/v1/conferences
GET /api/v1/conferences/<id>
```
